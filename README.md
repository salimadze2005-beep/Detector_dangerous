# Detector Dangerous

Локальное приложение для Windows 10/11 для мониторинга камер и микрофонов, фиксации тревожных событий и ведения журнала инцидентов. Интерфейс построен на PyQt6. Обработка выполняется локально.

В репозитории нет весов моделей, реальных адресов камер, паролей, пользовательских конфигураций, журналов событий и брендовых материалов. Публичные модели загружаются установщиком.

## Возможности

- локальные камеры, видеофайлы и RTSP-источники;
- анализ позы человека и фиксация длительного горизонтального положения;
- анализ импульсных звуков с калибровкой по фоновому шуму;
- локальное распознавание заданных русских тревожных слов;
- SQLite-журнал событий;
- снимки и видеоклипы инцидентов;
- PyQt6-интерфейс с настройками и историей;
- JSON webhook и отдельная доставка видеоклипа;
- CPU-режим и использование NVIDIA GPU при наличии совместимого окружения.

Это инженерный прототип. Перед применением на реальном объекте требуется проверка и калибровка.

## Быстрый запуск

На Windows 10/11:

```bat
install_and_run.bat
```

Или по шагам:

```bat
setup.bat
run.bat
```

Установщик создаёт виртуальное окружение, устанавливает зависимости, загружает публичные модели, выполняет диагностику и запускает тесты.

## Модели

Основные модели и дополнительные checkpoints не хранятся в Git. Их загрузка выполняется скриптами проекта и `tools/bootstrap.py`.

Для диагностики после установки:

```bat
verify_install.bat
```

## Настройка

Шаблон настроек находится в `detector_config.example.json`. Рабочий `detector_config.json` создаётся локально и исключён из Git.

Пример источника камеры:

```text
0
1
D:\video\test.mp4
rtsp://192.0.2.10/stream
```

Не публикуйте рабочую конфигурацию, если в ней находятся реальные адреса камер, логины, пароли или внутренние URL.

## Структура

```text
audio/      захват звука, калибровка и аудиодетекторы
video/      анализ видеопотока и положения человека
core/       конфигурация, события, SQLite, кадры и доставка
ui/         PyQt6-интерфейс
tools/      установка моделей, диагностика и вспомогательные утилиты
tests/      unit и integration тесты
docs/       документация по событиям и переносу
```

## Проверка

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
.venv\Scripts\python.exe tools\doctor.py --full
```

## Что не хранится в репозитории

- веса и checkpoints моделей;
- `detector_config.json`;
- содержимое `data/`;
- реальные видео и записи микрофона;
- RTSP-адреса с учётными данными;
- внутренние webhook URL;
- локальные логи и базы данных.
